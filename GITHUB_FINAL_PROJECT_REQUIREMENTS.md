## Overview

In this assignment you will create a personal profile website, publish it with GitHub Pages, and link it from the course landing page. Your work lives in its own folder on its own branch, so it never interferes with your classmates' work.

**By the end you will have:**

1. Your own branch and personal folder in the course repo
2. A profile page (`index.html`) that meets every requirement in Part 3
3. A published GitHub Pages site
4. Your profile card on the course landing page linking to your GitHub profile and your portfolio site

## Part 1: Project Setup and Repository Instructions

### Step 1. Locate the course root folder

Open the cloned GitHub repository on your computer:

| OS | Path |
|----|------|
| **Windows** | `C:\Users\[Your Username]\Documents\GitHub\NLU-CSS-100-33-90621-2026-Fall-Sep21-Dec4-Wed_1-4pm` |
| **macOS** | `/Users/[Your Username]/Documents/GitHub/NLU-CSS-100-33-90621-2026-Fall-Sep21-Dec4-Wed_1-4pm` |

### Step 2. Create a separate branch

Before adding any files, you **must** create your own working branch, separate from the main development branch. This keeps your changes isolated so they only affect your project.

- Suggested branch name: the same as your folder name (e.g., `john_doe`)
- Need help? Read [Managing branches in GitHub Desktop](https://docs.github.com/en/desktop/making-changes-in-a-branch/managing-branches-in-github-desktop).

### Step 3. Create your personal directory

Inside the course root folder, create a new folder using your **first and last name separated by an underscore** (e.g., `john_doe`).

```
NLU-CSS-100-33-90621-2026-Fall-Sep21-Dec4-Wed_1-4pm/
└── john_doe/
```

### Step 4. Add your assignment files

All of your work must be saved **exclusively** inside your personal directory. Your folder must contain:

- `index.html` (your profile page)
- Any additional files required for your project (CSS, images, JavaScript, etc.)

```
john_doe/
├── index.html
├── css/
│   └── styles.css
└── images/
    └── profile.jpg
```

## Part 3: What Your Profile Website Must Have

### A. Header / Hero section
- Your **name**
- Your **degree**
- **Class of 202#** (e.g., Class of 2028)
- A button that says **"Visit my GitHub"** or **"View GitHub Repos"**
- A button that says **"View my projects"**

### B. About Me
- A short section introducing yourself

### C. Skills
- **Technical skills / hard skills**
- **Soft skills**

### D. Projects and Academic Journey
- A clear section for **each course** you have taken or are taking
- A **Highlighted Projects** section
- Each project card must link to **that project's repository on your GitHub**

### E. Footer: "Let's Connect"
- A **Let's Connect** section at the bottom of the page (the footer)
- Include links to: **LinkedIn**, **GitHub**, **Twitter / X**, and/or any other social media you want others to connect with
